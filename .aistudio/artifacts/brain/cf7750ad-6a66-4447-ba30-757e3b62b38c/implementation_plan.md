# Writing Helper 레이아웃 최적화 및 헤더 디자인 개선 계획

## 1. 개요 및 변경 목적
사용자가 첨부한 화면 캡처에서 확인된 두 가지 UI 불편 사항을 완벽히 해결합니다:
1. **가운데 과도한 빈 공간 제거 및 결과물 형식 영역 끌어올림**: 주제/요구사항 및 4개 선택 상자(전문 분야, 작업 유형, 대상 독자, 작성 분량)와 결과물 형식(오렌지색 구분선) 사이에 발생한 불필요한 넓은 공백을 제거하여, '결과물 형식'과 'GPT로 즉시 실행' 버튼이 화면 아래로 밀려나지 않고 한눈에 들어오도록 밀착 배치합니다.
2. **헤더 타이틀 및 아이콘 확대 & 가운데 정렬**: 상단 헤더의 앱 아이콘과 `Writing Helper` 텍스트 크기를 더 크고 선명하게 확대하고, 상단 영역의 중앙에 균형 있게 정렬합니다.

---

## 2. 세부 변경 사항 점검

### A. 메인 화면(글쓰기 탭) 레이아웃 및 여백 수정
- **현재 상태**: 상단 입력부와 하단 결과물 형식 영역 사이에 카드 컨테이너의 flex 확장 또는 과도한 마진으로 인해 큰 여백이 발생하여 하단 버튼이 스크롤되거나 화면 밖으로 밀려남.
- **수정 내용**:
  1. 4개 드롭다운 선택창(전문 분야, 작업 유형, 대상 독자, 작성 분량) 바로 아래에 오렌지색 구분선(`border-top: 2px solid #f97316`)과 '결과물 형식 (복수 선택 가능)' 섹션을 즉시 연결 배치.
  2. 불필요한 공백을 완전히 제거하여 한 화면(Viewport 100dvh) 내에 상단 헤더부터 'GPT로 즉시 실행' 버튼까지 스크롤 없이 깔끔하게 표시.
  3. 필요 시 세로 화면이 작은 모바일 기기에서도 전체 카드가 자연스럽게 스크롤될 수 있도록 안전한 반응형 높이 적용.

### B. 상단 헤더(Header) 타이틀 및 기호(아이콘) 개선
- **현재 상태**: 아이콘과 텍스트가 좌측으로 쏠려 있고 크기가 다소 작음.
- **수정 내용**:
  1. **아이콘 크기 확대**: 노트 & 펜 아이콘의 크기를 기존(w-7~8)에서 **36px~40px(w-9~10)** 수준으로 키우고 모서리 곡률과 그림자를 강화하여 선명도 향상.
  2. **Writing Helper 텍스트 확대**: 폰트 크기를 **24px~28px(text-2xl~3xl)**의 굵은 폰트(`font-extrabold`)로 확대하고 텍스트 그림자를 입혀 가독성 극대화.
  3. **가운데 정렬(Center Alignment)**: 아이콘과 'Writing Helper' 텍스트를 상단 헤더 중앙에 완벽히 정렬(`justify-center`).
  4. **설치 버튼 배치 조화**: 우측 상단에 위치한 '앱 설치' / '앱 설치됨' 배지는 우측 상단에 절대 위치(`absolute right-3`) 또는 헤더 우측에 배치하여 메인 타이틀의 완벽한 중앙 정렬을 방해하지 않도록 처리.

```
┌────────────────────────────────────────────────────────┐
│ [헤더] ─────────────────────────────────────────────── │
│   (우측 상단: [앱 설치])                                │
│        [ 펜 & 노트 아이콘 ]  Writing Helper (확대 & 중앙)│
│   [  글쓰기  ]  [ 작성 세부 설정 ]  [ 기본 프롬프트 ]   │
├────────────────────────────────────────────────────────┤
│ [글쓰기 본문 카드]                                    │
│   작성 내용 입력                     [미리보기] [초기화] │
│   [ 주제·질문·작성할 내용을 입력한다...             ]   │
│   [ 추가 요구사항...                                ]   │
│   ┌──────────────────────┬──────────────────────┐      │
│   │ 전문 분야: 자동 판별 │ 작업 유형: 자동 판별 │      │
│   │ 대상 독자: 맞게 판단 │ 작성 분량: 맞게 판단 │      │
│   └──────────────────────┴──────────────────────┘      │
│   ──────────────── 오렌지색 구분선 ─────────────────   │
│   결과물 형식 (복수 선택 가능)                          │
│   ┌───────────┬───────────┐                            │
│   │ 완성 원고 │ 연구 보고서│                            │
│   │ 블로그 글 │ 강의안    │                            │
│   │ 실무 문서 │ 영상 대본 │                            │
│   │ 핵심 요약 │ GPT 즉시실행│                           │
│   └───────────┴───────────┘                            │
└────────────────────────────────────────────────────────┘
```
